# Lenovo Toolkit v1.0.4

[Tiếng Việt](#tiếng-việt) · [English](#english)

## Tiếng Việt

### Bộ cài đặt mới

- Thêm trình cài đặt và gỡ cài đặt một file `lenovo-toolkit-setup-v1.0.4-x64.exe` viết bằng Rust, đóng gói sẵn cả `lenovo-toolkit.exe` và `lenovo-toolkit-cli.exe`.
- Giao diện tự theo chế độ sáng hoặc tối của Windows, có nút đổi nhanh tiếng Việt và tiếng Anh, cho chọn thư mục cài đặt và hiển thị rõ quyền quản trị (UAC) cùng những thay đổi trên máy trước khi bấm cài.
- Tự tắt bản đang chạy khi cập nhật, tạo lối tắt ở Start Menu và Desktop, đăng ký gỡ cài đặt trong Windows Settings -> Apps và tạo Scheduled Task `LenovoToolkit_Autorun` chạy thẳng `lenovo-toolkit.exe --minimized` để không chớp cửa sổ terminal lúc khởi động.
- Thêm script `tools/build-dist.ps1` tự đóng gói bản cài đặt, bản chạy thẳng và bản CLI kèm số phiên bản vào thư mục `dist/`.

## English

### New installer

- Added a single-file Rust installer and uninstaller `lenovo-toolkit-setup-v1.0.4-x64.exe` that bundles both `lenovo-toolkit.exe` and `lenovo-toolkit-cli.exe`.
- Follows the Windows light or dark theme, switches between Vietnamese and English, lets you pick the installation folder, and lists UAC requirements and system changes up front.
- Stops a running instance before upgrading, creates Start Menu and Desktop shortcuts, registers in Windows Settings -> Apps, and creates the `LenovoToolkit_Autorun` scheduled task launching `lenovo-toolkit.exe --minimized` directly with no console flash at logon.
- Added `tools/build-dist.ps1` to output versioned setup, portable, and CLI binaries into `dist/`.
