# Lenovo Toolkit v1.0.1

[Tiếng Việt](#tiếng-việt) · [English](#english)

## Tiếng Việt

Bản phát hành đầu tiên. Lenovo Toolkit là bản viết lại bằng Rust của LenovoLegionToolkit, dành cho Legion, LOQ và IdeaPad Gaming trên Windows 11 (x64).

### Có gì

- Chế độ nguồn Quiet, Balance, Performance, Extreme, Custom và Fn+Q. Ở Balance có công tắc AI Engine.
- Custom mode với mặc định của Lenovo bị khóa và một cấu hình tự chỉnh có cảnh báo.
- Quạt và cảm biến, chế độ sạc pin, sạc qua đêm, luôn bật sạc USB, trang Pin chi tiết.
- Chế độ GPU, tần số quét (Fn+R), đèn bàn phím, khóa touchpad, khóa Fn và phím Windows, tắt mic bằng Fn+F4.
- Thông báo phím có icon, tắt được từng loại.
- Vô hiệu hóa Vantage, Legion Zone, Legion Space và dịch vụ phím nóng Lenovo.
- Chạy ẩn dưới khay, tooltip thông số khi rê chuột, tự chạy cùng Windows.

### Tải về

- `lenovo-toolkit.exe`: ứng dụng.
- `lenovo-toolkit-cli.exe`: dòng lệnh (không bắt buộc).

Ứng dụng cần quyền quản trị và chưa ký số, nên Windows có thể hiện cảnh báo SmartScreen. Chỉ tải từ trang Releases của repository này.

### Lưu ý

- Máy ThinkBook, IdeaPad, Slim, Yoga chưa được hỗ trợ: ứng dụng chỉ đọc cảm biến.
- Mới thử trên Legion Y7000 IRX9 chạy Windows 11.
- Chưa có thông báo cho bộ sạc AC, Caps Lock, Num Lock và phím Fn+F8.

## English

First release. Lenovo Toolkit is a Rust rewrite of LenovoLegionToolkit for Legion, LOQ and IdeaPad Gaming laptops on Windows 11 (x64).

### What's in it

- Quiet, Balance, Performance, Extreme and Custom power modes, plus Fn+Q. Balance has an AI Engine switch.
- Custom mode with a locked Lenovo default and an editable preset that warns on risky values.
- Fans and sensors, battery charge mode, overnight charge, always-on USB and a detailed Battery page.
- GPU working mode, refresh rate (Fn+R), keyboard backlight, touchpad lock, Fn and Windows key lock, Fn+F4 mic mute.
- Key notifications with icons, each type can be turned off.
- Disable Vantage, Legion Zone, Legion Space and the Lenovo hotkey service.
- Runs hidden in the tray, shows stats on hover, starts with Windows.

### Downloads

- `lenovo-toolkit.exe`: the app.
- `lenovo-toolkit-cli.exe`: the command line (optional).

The app needs administrator rights and is not code-signed, so Windows may show a SmartScreen warning. Download it only from this repository's Releases.

### Notes

- ThinkBook, IdeaPad, Slim and Yoga laptops are not supported yet: the app only reads sensors there.
- Tested only on a Legion Y7000 IRX9 running Windows 11.
- No notifications yet for the AC adapter, Caps Lock, Num Lock or the Fn+F8 key.
