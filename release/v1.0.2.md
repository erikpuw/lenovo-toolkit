# Lenovo Toolkit v1.0.2

[Tiếng Việt](#tiếng-việt) · [English](#english)

## Tiếng Việt

### Sửa lỗi

- Máy không còn nóng lên vì ứng dụng. Bản v1.0.1 hỏi số liệu GPU qua NVAPI mỗi 2 giây ở trang Home và khi rê chuột vào khay, việc đó đánh thức card NVIDIA đang ngủ. Giờ ứng dụng hỏi Windows trạng thái card trước và chỉ đọc số liệu khi card đang chạy, giống bản gốc.
- Nhiệt độ GPU lấy từ NVAPI trước rồi mới tới EC của Lenovo, mức tải GPU hiện "-" khi card ngủ, như bản gốc.

### Thay đổi

- Thẻ card đồ họa rời hiện trạng thái và nút "Ngắt kích hoạt" như bản gốc. Nút chỉ bấm được khi card đang chạy.
- Thêm mục Thông tin trong Cài đặt: phiên bản, mã nguồn, giấy phép và ghi công tác giả gốc.

## English

### Fixes

- The app no longer heats up the laptop. v1.0.1 queried NVAPI every 2 seconds on the Home page and when hovering the tray icon, which woke a sleeping NVIDIA GPU. The app now asks Windows for the GPU power state first and reads stats only while the GPU is running, like the original.
- GPU temperature comes from NVAPI first and from the Lenovo EC otherwise, and GPU usage shows "-" while the GPU sleeps, like the original.

### Changes

- The discrete GPU card shows its state and a "Deactivate" button, as in the original. The button works only while the GPU is running.
- New About section in Settings: version, source code, license and credits to the original authors.
